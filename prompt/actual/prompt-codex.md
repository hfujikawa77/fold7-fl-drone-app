# プロンプト履歴（Codex）

アプリ構築時にユーザーが Codex へ送信した主なプロンプトを時系列で整理しました。  
ログ抽出元: 対話履歴および `logs/reverse_prompt.txt`。

| # | プロンプト内容 | 補足 |

| 3 | OK。そのように修正してください。 | 提案された修正の実施依頼 |

|18 | ビルドエラー | `cleanMergeDebugAssets` 失敗の報告 |
|19 | 機体の移動軌跡を描画して。オートパンのチェックボックスを付けてチェックありなら機体が中心になるようにして。 | 地図機能拡張の依頼 |
|20 | README.md は 日本語にして | README の全訳依頼 |
